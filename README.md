# Su-Arpha Portfolio

Personal freelance developer portfolio for Su-Arpha Kanklap. Next.js (App Router) + plain CSS, no UI libraries or backend — static by design, deployed on Vercel.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `app/` — root layout, metadata, `robots.js` / `sitemap.js`
- `components/` — one component + CSS module per section
- `lib/content.js` — all copy, project, skill and experience data in one place
